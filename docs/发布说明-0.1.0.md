# Todox 0.1.0

首个公开版本。中文优先的 Windows 桌面待办应用 —— 写一句话就能建任务、到点真的会响、关掉窗口也不占内存。

**完全离线**：没有账号、没有云端、没有遥测。你的任务就是本地一个 SQLite 文件。

## 装好之后，先试这三步

### 1. 验证提醒真的会响

按 `Ctrl+Alt+Space` 唤出悬浮窗，输入：

```
30秒后 测试提醒
```

回车，等 30 秒。右下角会出现一条**停留不消失**的通知，带「打开 Todox」
和「稍后提醒」两个按钮。

这条通知用的是 Windows 的「提醒（reminder）」场景 —— 它不会像普通通知那样
几秒后自动消失，而是等你处理。这是刻意的：**错过的提醒等于没有提醒**。

### 2. 记一件明天要做的事

输入 `明天下午3点 交房租`，你会看到实时预览显示它被理解成了什么。

### 3. 建一个每周重复的任务

输入 `每周一早上9点 提交周报`。在列表里勾选它 —— 这一轮完成的同时会
**自动推进到下一个周一**。

## 这个版本有什么

### 输入

- 中文自然语言，**保存前实时预览**（你能看到它怎么被理解的）
- 秒级粒度：`10秒后 提醒我`
- 时间点 / 日期 / 相对时长 / 重复规则，四类表达都支持
- 「已过则顺延」：说「下午3点」而现在已经 16:00 → 自动落到明天

### 提醒

- **到点真的会响**：用 Windows 的 reminder 通知场景，停留直到你处理
- 通知里可直接**打开应用**或**稍后提醒**
- 分级提醒：截止型任务默认「前 1 天 / 前 1 小时 / 到点」，可增删
- 全天任务提醒钟点可配（默认 09:00），不会半夜弹
- 勿扰时段，支持跨午夜
- **错过补发**：应用没运行时错过的提醒，下次启动汇总成横幅告知

### 组织

- 今天 / 收件箱 / 即将到期 / 全部，四个列表视图
- 日历月视图 + 选中某天的日视图
- 完成统计：概览 · 每日柱状图 · 按任务排行
- 逾期任务始终出现在「今天」顶部并标红 —— 逾期项若被藏起来，你就会彻底忘掉它

### 随手记

- 全局快捷键 `Ctrl+Alt+Space` 唤出**置顶悬浮窗**：最近 6 件事 + 输入框
- 打开即聚焦、回车即保存、可连续录入、失焦自动隐藏
- 悬浮窗与主窗口共用同一套解析逻辑，行为完全一致

### 数据

- JSON 导入导出，支持「清空并复原」与「仅合并」两种模式
- 托盘常驻，关窗不退出，提醒照常工作
- 开机自启（可选）

## 资源占用

实测数据（release 构建，按父子进程关系精确筛选）：

| 场景 | 内存 | 目标 | 结论 |
|---|---|---|---|
| **托盘常驻**（关掉窗口） | **28–33 MB** | ≤120 MB | 达标 |
| 托盘空闲 CPU | **0 ms / 25 s** | 无轮询 | 达标 |
| 可执行文件 | 7.0 MB | — | — |
| 窗口可见时 | 354 MB | ≤120 MB | **未达标** |

### 关于窗口可见时的 354 MB

这一项**超标**，我没有把它藏起来。

原因是 WebView2（Windows 上 Tauri 用的 Chromium 内核）有 6 个子进程，
合计约 354 MB。这是 Chromium 的固有开销，无法通过优化代码消除。

**能做的只是让它不常驻**：关掉窗口时销毁整个 WebView，释放 **321 MB**。

```
打开窗口 → 354 MB      关掉窗口 → 28 MB
```

若要求窗口可见时也 ≤120 MB，整个 WebView 方案就不成立，需要改用
WinUI/WPF 原生重写界面 —— 那是另一个量级的工程。

## 已知问题

这些是我**知道且暂未解决**的，写出来而不是藏起来：

| 问题 | 说明 |
|---|---|
| 窗口可见时内存 354 MB | 见上文，WebView2 固有开销 |
| 导入不支持超大备份 | 超过 100 MB 会被拒绝（避免 WebView 崩溃） |
| 导入的畸形行不计数 | 恢复备份时可能静默丢行 |
| 没有代码签名 | 首次运行有 SmartScreen 提示 |
| 只有中文界面 | 项目定位是中文优先 |
| 应用图标是脚手架默认的 | 尚未设计专属图标 |

### 如果通知不弹

按顺序排查：

1. **设置 → 系统 → 通知**，确认 `Windows PowerShell` 的通知权限开着
   （Todox 通过它弹通知，原因见
   [设计决策](https://github.com/toweralpha/Todox/blob/main/docs/设计决策.md)）
2. 检查专注助手 / 勿扰模式
3. 检查 Todox 自己的设置 → 通知，以及勿扰时段

### 如果 `Ctrl+Alt+Space` 没反应

快捷键可能被别的程序占用（输入法、截图工具很常见）。启动时若注册失败会
打印提示。可以改用托盘图标左键，或关掉占用该快捷键的程序。

```
%APPDATA%\com.tower.todox\todox.db
```

标准 SQLite 文件，可用任何 SQLite 工具读写。

**卸载程序不会删除你的数据**（刻意的 —— 卸载后重装不该丢任务）。
要彻底清理，手动删掉上面的目录。

## 技术栈

Tauri 2 · Rust · Svelte 5 · SQLite · TypeScript

- **241 个测试**（212 单元 + 29 集成），clippy 零警告
- 零轮询调度器：`sleep_until(下一个触发时刻)` + 唤醒通道，空闲 CPU 为 0
- 领域逻辑与 IO 分离，时间戳一律带本地时区偏移
- 数据库表结构从一开始就预留了云同步所需的字段（UUID 主键、
  `updated_at`、`deleted_at`、`revision`、`changelog`）
